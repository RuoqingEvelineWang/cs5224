This repo consists of a skeleton for the following:
 - frontend: Uses react and Amazon Amplify (connected to Cognito). Has a default sign up/log in page and homepage.
    - code generated by npx create-react-app
    - sample code in App.js, CreateEvent.js and EventList.js generated by AI
 - backend: Uses AWS CDK (abstraction layer in typescript instead of using YAML), CloudFormation (automated management of AWS resources), DynamoDB (NoSQL key value store), Lambda (serverless functions), API Gateway
    - code in /cdk generated by init: cdk init app --language typescript
    - sample code in /cdk/lib/cdk-stack.ts generated by AI
    - sample code in /lambda/index.js generated by AI

Initial setup steps
1. clone git repo
2. run following commands to set up AWS:
brew install awscli
npm install -g aws-cdk
aws configure (will ask for access key, which can be set up on aws console: Security credentials - create access key)
3. run following command inside /backend/cdk folder to set up CDK:
cdk bootstrap aws://[accountID]/[region] (can be found on AWS console)
4. the above command will generate CdkStack.UserPoolClientId and CdkStack.UserPoolId, copy these into .env file for authentication
5. run following command inside /backend/cdk to deploy backend to AWS:
cdk deploy
6. run following command inside /frontend to install libraries:
npm install
7. run following command inside /frontend to to start front end:
npm start

Development steps
1. if backend code is updated, run cdk deploy again to update (some config changes will require recreating stack)
2. if frontend code is updated, the react page from npm start will be refreshed and updated automatically
